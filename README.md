# Case Study Snippets

Illustrative code from a selection of engineering case studies on my portfolio site. Each folder holds one snippet plus a short write-up of the decision behind it.

These are extracted, standalone illustrations of a specific pattern or decision, not full production systems. Each README links back to the full case study, which covers the investigation, the trade-offs, and the outcome in more depth.

## Case studies

- **[async-ingestion-pipeline](./async-ingestion-pipeline)** — diagnosing a silent failure caused by a blocking call hidden inside an async task
- **[webhook-validation-layer](./webhook-validation-layer)** — a defense in depth validation layer balancing strict security against high availability
- **[fault-tolerant-data-feed](./fault-tolerant-data-feed)** — an automated pipeline designed to never let bad state replace good state
